# Requisitos de seguridad — Plataforma

Secretos, cifrado, **subida y entrega de archivos**, límites de uso y la documentación
de la API. Son capacidades compartidas: valen para **todo** archivo que entre a Monkey, venga del onboarding o
de una evidencia.

Tablero, estados y reglas de uso: [`README.md`](README.md). Cómo funciona el módulo: [`arquitectura/plataforma/`](../arquitectura/plataforma/README.md).
